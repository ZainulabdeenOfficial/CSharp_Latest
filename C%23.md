# C# Language Concepts (Complete Guide)

## What is C#?
C# (pronounced "C-sharp") is a modern, type-safe, object-oriented programming language developed by Microsoft for the .NET platform.

---

## 1. Value Types vs Reference Types

| Value Types | Reference Types |
|-------------|----------------|
| Stored on stack | Stored on heap |
| Holds actual data | Holds reference to data |
| Copy creates new copy | Copy shares reference |
| `struct`, `enum`, primitive types | `class`, `string`, `array`, `delegate` |

```csharp
int a = 10;        // value type
int b = a;         // copy (independent)

int[] arr1 = { 1 }; // reference type
int[] arr2 = arr1;  // same array (both point to same data)
```

## 2. Data Types

### Primitive Types
```csharp
byte b = 255;          // 0 to 255
short s = 32767;       // -32K to 32K
int i = 2147483647;    // -2B to 2B
long l = 9223372036854775807L;
float f = 3.14f;       // ~7 digits precision
double d = 3.14;       // ~15 digits precision
decimal m = 3.14m;     // 28-29 digits (for money)
char c = 'A';          // single character
bool flag = true;      // true/false
```

### Reference Types
```csharp
string s = "Hello";    // immutable
object o = "anything"; // base type of everything
dynamic dyn = 10;      // type resolved at runtime
```

### Nullable Types
```csharp
int? age = null;       // nullable value type
int value = age ?? 0;  // null-coalescing
```

## 3. Type Conversion

```csharp
// Implicit (safe)
int i = 100;
double d = i;          // int → double (automatic)

// Explicit (cast) - may lose data
double d = 9.8;
int i = (int)d;        // → 9 (decimal lost)

// Using Convert class
int i = Convert.ToInt32("123");

// Parsing
int i = int.Parse("123");
bool ok = int.TryParse("abc", out i);  // safe, returns false
```

## 5. Control Structures

```csharp

    1 => "Monday",

    _ => "Unknown"
```

## 8. Collections

| Collection | Description | When to Use |
|-----------|-------------|-------------|
| `List<T>` | Dynamic array | Need ordered, indexed items |
| `Dictionary<TKey,TValue>` | Key-value pairs | Fast lookup by key |
| `HashSet<T>` | Unique elements | No duplicates needed |
| `Queue<T>` | FIFO | First-in-first-out |
| `Stack<T>` | LIFO | Last-in-first-out |
| `LinkedList<T>` | Doubly linked list | Frequent insert/delete |

```csharp
var list = new List<int> { 1, 2, 3 };
list.Add(4); list.Remove(2);

var dict = new Dictionary<string, int> { ["A"] = 1 };
dict.ContainsKey("A");

var set = new HashSet<int> { 1, 2, 3 };
set.Add(1); // ignored (already exists)
```

## 9. LINQ (Language Integrated Query)

Query data from any source (objects, SQL, XML, etc.)

```csharp
var numbers = new List<int> { 1, 2, 3, 4, 5, 6 };

// Method syntax
var evens = numbers.Where(n => n % 2 == 0);
var sorted = numbers.OrderByDescending(n => n);
var first = numbers.FirstOrDefault(n => n > 3);
var all = numbers.All(n => n > 0);          // true
var any = numbers.Any(n => n > 10);         // false
var sum = numbers.Sum();
var avg = numbers.Average();
var grouped = numbers.GroupBy(n => n % 2);
```

## 10. Delegates & Events

```csharp
// Delegate = type-safe function pointer
public delegate int Operation(int x, int y);

int result = op(2, 3);

// Func & Action (built-in delegates)
Func<int, int, int> add = (a, b) => a + b;
Action<string> print = msg => Console.WriteLine(msg);

// Event
public event EventHandler ButtonClicked;
button.Click += (s, e) => Console.WriteLine("Clicked!");
```

## 11. Async / Await

```csharp
public async Task<string> FetchDataAsync()
{
    using var client = new HttpClient();
    string result = await client.GetStringAsync(url);
    return result;
}

// Call
string data = await FetchDataAsync();

// Async patterns
await Task.WhenAll(task1, task2);    // wait for all
await Task.WhenAny(task1, task2);    // first to finish
Task.Run(() => DoWork());            // background thread
```

## 12. Exception Handling

```csharp
try
{
    int x = 10 / 0;
}
catch (DivideByZeroException ex) when (Log(ex))  // exception filter
{
    Console.WriteLine(ex.Message);
}
catch (Exception ex)
{
    // log, rethrow, or handle
    throw;  // preserves stack trace
}
finally
{
    // always runs (cleanup)
}

// Custom exception
public class MyException : Exception
{
    public MyException(string msg) : base(msg) { }
}
```

## 13. Generics

```csharp
public class Repository<T> where T : class
{
    public T Get(int id) { /* ... */ }
    public void Add(T item) { /* ... */ }
}

// Constraints
where T : struct      // value type
where T : class       // reference type
where T : new()       // parameterless constructor
where T : IComparable // implements interface
T? item = default;    // default value (null for ref, 0 for value)
```

## 17. Common Keywords Reference

| Keyword | Purpose |
|---------|---------|
| `var` | Implicit type (compiler decides) |
| `dynamic` | Runtime type resolution |
| `const` | Compile-time constant |
| `readonly` | Runtime constant (can set in constructor) |
| `static` | Belongs to class, not instance |
| `sealed` | Cannot be inherited |
| `abstract` | Must be overridden in derived class |
| `virtual` | Can be overridden |
| `override` | Override a virtual method |
| `partial` | Split class/method across files |
| `async` | Marks method as asynchronous |
| `await` | Waits for async task to complete |
| `yield` | Iterator state machine |
| `unsafe` | Allows pointer operations |
| `record` | Immutable reference type (C# 9+) |
| `struct` | Value type |

## 18. Garbage Collection

- .NET automatically manages memory
- GC runs when memory is low
- `IDisposable` + `using` for unmanaged resources
```csharp
using var file = new StreamReader("file.txt");
// automatically disposed at end
```

## 19. Threading & Concurrency

```csharp
// Task-based (modern)
Task task = Task.Run(() => DoWork());
await task;

// Parallel (for CPU-bound)
Parallel.For(0, 100, i => Process(i));

// Lock for thread safety
private readonly object _lock = new();
lock (_lock) { sharedResource++; }
```

---

## 20. Quick Tips

- `string` is immutable (use `StringBuilder` for heavy manipulation)
- Use `Task` over `Thread` (modern, efficient)
- Prefer `List<T>` over `ArrayList`
- Use `var` when type is obvious
- Always use `using` for `IDisposable` resources
- Prefer `async/await` over `ContinueWith`
- Use `nameof` instead of string literals for member names
